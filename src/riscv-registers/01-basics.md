# 01 前提词与全貌

## 前提词

后面几篇要用到的词，先在这里定义。

- 两层规范。RISC-V 的 ISA 规范分非特权卷和特权卷，规定硬件上有哪些寄存器、指令怎么编码、
  trap 时硬件做什么。psABI（RISC-V ELF psABI）规定软件之间怎么用这些寄存器：参数放在哪里，
  哪些寄存器由调用者保存、哪些由被调用者保存，目标文件里有哪些重定位。硬件对 x1–x31
  几乎一视同仁，ra、sp、a0 这些名字和角色大多是 psABI 定的。
- XLEN：整数寄存器的位宽，RV32 是 32，RV64 是 64。
- FLEN：浮点寄存器的位宽，只有 F 扩展时是 32，有 D 扩展时是 64。
- VLEN：向量寄存器的位宽，由具体处理器决定，程序运行时才知道。
- 扩展。`-march` 的字符串由一个基础集和若干扩展组成。本专题用到的：
  - I：基础整数指令集。
  - E：只有 16 个整数寄存器的基础集，用来替代 I。
  - M：乘除。
  - F、D：单精度、双精度浮点。
  - C：16 位的压缩编码。LLVM 把 C 里整数部分的指令叫 Zca，开 C 就开了 Zca
    （`RISCV/RISCVFeatures.td:387`）。
  - V：向量。
  - Zicsr：CSR 读写指令。
  - Zfinx：浮点运算直接用整数寄存器。
  - Zcmp：压栈、出栈指令 cm.push、cm.popret 等。
- hart：一个硬件执行线程。每个 hart 有自己的一整套寄存器。
- 特权级：M（机器）、S（监管）、U（用户）。只跑裸机程序的小处理器常常只实现 M，或者 M 加 U。
- trap：异常和中断的统称。发生时处理器离开当前指令流，跳到 trap 入口。
- `-mabi` 的名字：
  - `ilp32`：int、long、指针都是 32 位，浮点参数经整数寄存器传。
  - `ilp32f`、`ilp32d`：float、double 参数经浮点寄存器传。
  - `ilp32e`：配 E 扩展。
  - RV64 上对应的是 lp64、lp64f、lp64d、lp64e。
- 调用者保存（caller-saved）：被调函数可以随意改写。调用者如果在调用之后还要用里面的值，
  得自己在调用之前把值挪走。
- 被调用者保存（callee-saved）：被调函数返回时，这些寄存器的值必须和进入时一样。
  被调函数要用它们，就得先存到栈上，返回前取回。
- 序言、尾声（prologue、epilogue）：函数入口处开栈帧、保存寄存器的几条指令，
  和返回前恢复寄存器、关栈帧的几条指令。
- 伪指令：汇编器接受、硬件上没有的写法，汇编时换成一条或几条真实指令，例如 `li`、`mv`、`ret`、`call`。
- 链接器松弛（relaxation）：链接时知道了符号的最终地址，把某些指令序列改写成更短的等价序列。
- LLVM 里的寄存器。LLVM 后端先把程序变成 MIR（Machine IR，一种每条大致对应一条机器指令的
  中间表示）。寄存器分配之前，MIR 用的是数量不限的虚拟寄存器 `%0`、`%1`……；寄存器分配把它们
  换成物理寄存器，即 x0–x31 这些真实存在的寄存器。
- 寄存器类（register class）：一组可以互相替换的物理寄存器。每条指令的每个操作数声明自己接受
  哪个类，寄存器分配只在这个类里挑。
- TableGen 与 `.td` 文件：LLVM 用一种叫 TableGen 的描述语言写寄存器、指令、调用约定，文件扩展名
  是 `.td`，构建时由它生成 C++ 代码里用的表。后文引用的 `RISCVRegisterInfo.td` 等都是这种文件。

## 全貌

```
pc         1 个     XLEN 位   不是通用寄存器，指令不能把它当操作数
x0–x31    32 个     XLEN 位   I；E 只有 x0–x15
f0–f31    32 个     FLEN 位   F/D；开 Zfinx 时没有这一组
v0–v31    32 个     VLEN 位   V
CSR       地址 12 位，最多 4096 个；只能用 csr 开头的指令访问
```

- pc 只能间接读写。`auipc rd, imm` 把 pc + (imm << 12) 写进 rd；jal、jalr 把下一条指令的地址
  写进 rd；除此之外没有指令能读 pc。改写 pc 的是 jal、jalr 和分支指令。
  `ex/gp/main.c` 的反汇编里，`auipc gp, 0x11` 就是以 pc 为基准算 gp 的值。
- x0–x31：02、03 两篇。
- f0–f31：04。
- v0–v31：05。
- CSR：06。
